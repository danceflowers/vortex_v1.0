一、严格对齐项（编码 / 数据布局 / 核心语义）
--------------------------------------------------------------------------------

1. ISA opcode 分组
   - custom-1 (EXT2, opcode=0x2B): tcgen05 TMEM 管理 + cp.async.bulk.tensor
   - custom-2 (EXT3, opcode=0x5B): tcgen05 sync + 完整 mbarrier 族
   - custom-3 (EXT4, opcode=0x7B): tcgen05 计算 (mma/ld/st/wait::ld/wait::st)
   按 RISC-V.docx 三组 opcode 严格分配。

2. funct3 + qualifier 编码哲学
   funct7 = 7-bit qualifier 承载 PTX `.modifier` 后缀；funct3 区分指令变体；
   每个变体只由 funct3 承载（用户硬性要求）。

3. idescriptor_t (32-bit)
   PTX §9.7.16.5.4 字段位段一一对应：
     [1:0]   sparsity_meta_sel
     [2]     sparsity_kind
     [7:4]   kind (8 种精度族)
     [15:8]  shape_m
     [23:16] shape_n
     [25:24] a_storage_layout
     [27:26] b_storage_layout
     [28]    output_negate
     [29]    saturate
     [30]    transpose_a
     [31]    transpose_b
   sizeof = 4 (static_assert).

4. tensor_map_t (128B)
   CUtensorMap 形态对齐：global_address / box_size[5] / global_stride[5] /
   element_strides[5] / element_type / interleave / swizzle / l2_promotion /
   oob_fill / rank。sizeof = 128 (static_assert).

5. mbarrier_state_t (8B)
   PTX §7.6.1 位段：
     [63:62] phase parity
     [61:32] pending_arrival_count (30b)
     [31:20] pending_tx_count (12b, 字节单位)
     [19:0]  expected_arrival_count (20b)
   sizeof = 8 (static_assert).

6. pending_tx 字节单位
   PTX §7.6.4 expect_tx / complete_tx 单位 = 字节。Core::mbarrier_expect_tx /
   mbarrier_complete_tx 直接接收 tx_bytes。

7. tcgen05.commit 语义修正（Plan §10.1.7 corrigendum）
   注册到 mbar 的 expected_arrival_count + pending_arrival_count（NOT
   pending_tx_count）。每个 tcgen05.async op 完成时
   on_async_tensor_op_completed() 调 mbarrier_arrive。

8. mbarrier phase parity 协议
   mbarrier_wait / test_wait / try_wait 全部用 phase parity bit 比较；phase
   advance 在 (pending_arrival_count == 0 && pending_tx_count >= expected_tx_count)
   时翻转 phase[63:62] 并重置计数器。LMEM mirror 在每次状态变更后写回。

9. TCU_MMA 5 操作数布局
   rd = d_taddr / rs1 = idesc (32-bit) / rs2 = operand_block_lmem_ptr (32B)。
   operand_block_t 容纳 a_taddr / b_sdesc(64-bit) / lanes_off。

10. d_taddr R-M-W 语义
    enable_input_d=1 时 d_taddr 同时是 C 输入和 D 输出（PTX 无独立 c_taddr）。

11. collector_a_state 编码到 qualifier
    qualifier[5:4] 表示 4 状态 fill/use/lastuse/discard。
    collector_b_state 不编码（B 在 .ws 永远 streaming，无 lifecycle）。

12. ordering 位 (.relaxed / .release / .acquire) 编码就位
    MBAR_ARRIVE / EXPECT_TX / COMPLETE_TX / WAIT / TEST_TRY_WAIT 各自的
    qualifier 中都有 ordering 位段。Vortex 当前 fence 模型 strong-only，
    .relaxed 退化为 strong（不破坏正确性）。

13. multicast::cluster / cta_group::2
    qualifier 位编码就位；单 cluster 单 CTA 模型行为退化为 cta-scope。

14. 描述符存放位置
    operand_block_t 在 LMEM；mbarrier_state_t 在 LMEM；tensor_map_t 在 DRAM
    constant 区；64-bit b_sdesc / s_desc 走 LMEM 中转（rs2 = LMEM 指针）。

15. tc_decode 范围收窄
    只解 TCU_MMA / TCU_LD / TCU_ST 三个 tensor 计算指令；其他全部由 Core 直接
    处理，不经 tc_decode。

--------------------------------------------------------------------------------

  → sim/simx/tensor/idescriptor.h::tensor_map_t (128B)

  → sim/simx/tensor/idescriptor.h::mbarrier_state_t (8B)

  → sim/simx/core.cpp::Core::try_advance_mbarrier_phase()
  → sim/simx/core.cpp::Core::mbarrier_wait/test_wait/try_wait()

  → Core::mbarrier_expect_tx(addr, tx_bytes)
  → Core::mbarrier_complete_tx(addr, tx_bytes)

PTX §9.7.16.2 shared memory descriptor (64-bit s_desc / b_sdesc)
  → operand_block_t::b_sdesc_lo/hi
  → tmem_cp 的 rs2 = LMEM 8B s_desc 指针

PTX §9.7.16.5.4 tcgen05.mma 指令描述符 (idesc 32-bit)
  → idescriptor_t (32-bit packed bitfield)

PTX §9.7.16.5.5 collector buffer 状态机
  → qualifier[5:4] (fill/use/lastuse/discard)

PTX §9.7.16.5.6 multicast::cluster
  → qualifier[6] (TCU_MMA) / qualifier[4] (CPABULK_TENSOR_LD)

PTX §9.7.16.5.7 tcgen05.commit (arrival count 路径)
  → Core::mbar_commit(): 注册 inflight async ops 到 mbar 的
    expected_arrival_count + pending_arrival_count；on_async_tensor_op_completed
    每完成一次 mbarrier_arrive(mbar)。
  ★ 与 cp.async.bulk.tensor.mbarrier::complete_tx::bytes 路径(走 pending_tx_count
    字节计数)严格区分；同一 mbar 可以同时被两条路径推进，phase 完成条件 =
    (pending_arrival_count == 0 AND pending_tx_count >= expected_tx_count)。
